

## قابلیت‌های اختصاصی بله

API بله بر پایه API بات تلگرام است اما برخی قابلیت‌ها **فقط در بله** وجود دارند.
این SDK آن‌ها را به‌صورت متدهای درجه‌یک ارائه می‌دهد:

| متد | کاربرد |
|---|---|
| `askReview($user_id, $delay_seconds)` | درخواست نظرسنجی از کاربر (فقط بله) |
| `inquireTransaction($transaction_id)` | استعلام وضعیت تراکنش پرداخت (فقط بله) |

نکته‌ها:

- پرداخت‌ها با فرآیند خود بله انجام می‌شود (`sendInvoice` / `createInvoiceLink` /
  `answerPreCheckoutQuery`) — API های استارز/بازی/بیزینس تلگرام وجود ندارند.
- لینک بات‌ها به شکل `ble.ir/<bot_username>?start=<parameter>` است.
- وب‌هوک فقط پورت‌های **44** و **88** را پشتیبانی می‌کند.
- دانلود فایل از `https://tapi.bale.ai/file/bot<token>/<file_path>` انجام می‌شود.

این کتابخانه متدهای مستندشده در [docs.bale.ai](https://docs.bale.ai/) (۵۱ متد)
را پیاده‌سازی می‌کند — متدهای مخصوص تلگرام (بازی، بیزینس، هدیه، استارز، نظرسنجی و …)
عمداً لحاظ نشده‌اند.
